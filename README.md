- **Use a clean browser session for eBay.** The single most repeated advice from long-term users is: open a fresh tab in a browser with no ad-blockers, no privacy extensions, no other cashback extensions running. Conflicting extensions are the number one cause of dropped tracking.
- **Click through TopCashback immediately before checkout.** Don't browse eBay for an hour, leave, come back tomorrow, and then buy. The tracking cookie has a limited lifetime. Click → shop → buy in one uninterrupted session.
